## How to Reproduce

### 1. VisLoc Evaluation

```bash
cd third_party/dust3r

python visloc.py \
  --model_name DUSt3R_ViTLarge_BaseDecoder_512_dpt \
  --dataset "VislocSevenScenes('datasets/7-scenes', subscene='heads', pairsfile='pose_based_top20', topk=1)" \
  --pnp_mode poselib \
  --reprojection_error_diag_ratio 0.008 \
  --output_dir outputs/visloc_baseline
```

### 2. Depth Evaluation

```bash
python scripts/eval_depth_pose.py \
  --dataset "datasets/7-scenes/heads" \
  --max-pairs 30 \
  --output "logs/depth_eval.json"
```

### 3. Generate Pairs File (if missing)

```bash
python scripts/generate_pose_based_pairs.py \
  --dataset_root "datasets/7-scenes" \
  --subscene heads \
  --topk 20
```
