## ⚠️ 重要注意事项

### 1. 使用python3

服务器上必须使用`python3`而不是`python`：
```bash
python3 scripts/train_distill.py --config expconfigs/distill.yaml
```

### 2. 保持会话运行

使用tmux保持会话运行：
```bash
# 创建会话
tmux new -s experiment

# 在会话中运行实验
python3 scripts/train_distill.py --config expconfigs/distill.yaml

# 断开连接（保持运行）
# 按 Ctrl+B，然后按 D

# 重新连接
tmux attach -t experiment
```

### 3. 监控GPU使用

```bash
# 实时监控GPU
watch -n 2 nvidia-smi

# 或使用
nvidia-smi -l 2
```
