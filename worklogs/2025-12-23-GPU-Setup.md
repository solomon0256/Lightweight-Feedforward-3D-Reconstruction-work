## 📝 操作记录

### 1. 问题诊断

用户反馈 baseline 测试使用 CPU 运行，但本地有 NVIDIA GPU。

**检查 GPU 状态**:
```powershell
nvidia-smi
```
输出确认有 RTX 3060 Laptop GPU (6GB)。

**检查 PyTorch CUDA 支持**:
```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```
输出:
```
PyTorch: 2.9.1+cpu
CUDA available: False
```

**问题根源**: 安装的是 CPU 版本的 PyTorch (`2.9.1+cpu`)

### 2. 安装 CUDA 版 PyTorch

**卸载 CPU 版本**:
```powershell
pip uninstall torch torchvision -y
```

**安装 CUDA 12.4 版本**:
```powershell
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
```

安装输出:
```
Successfully installed sympy-1.13.1 torch-2.6.0+cu124 torchvision-0.21.0+cu124
```

## ⚠️ 注意事项

### 1. RoPE2D 警告
```
Warning, cannot find cuda-compiled version of RoPE2D, using a slow pytorch version instead
```
- 这是正常警告，不影响功能
- 如需优化，可编译 CUDA 版本的 RoPE2D

### 2. autocast 弃用警告
```
FutureWarning: `torch.cuda.amp.autocast(args...)` is deprecated.
Please use `torch.amp.autocast('cuda', args...)` instead.
```
- 这是 PyTorch API 更新导致的
- dust3r 官方代码需要更新，但不影响功能

### 3. 显存使用
- 当前峰值: 2.77 GB
- 剩余可用: ~3.4 GB
- 足够进行轻量化实验
