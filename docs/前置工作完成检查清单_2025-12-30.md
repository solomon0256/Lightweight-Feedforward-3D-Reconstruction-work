
**时间**: 20小时（卡1）

**同时运行**（卡2）:
```bash
# 运行量化（Q-only）
python scripts/quantize.py --config expconfigs/quant.yaml --mode auto
```

**时间**: 10小时（卡2）

#### 阶段2: K→Q（组合）
```bash
# 等待K-only完成后，运行K→Q

    --mode auto \
    --model-weights outputs/checkpoints/student_fp32_best.pth
```
