## 技术要点和实践方法

### 分块验证原理（核心设计思想）
**理论基础**：轻量化操作是确定性的，1个样本的结果可以代表1000个样本的结果

| 方法 | 分块原理 | 验证方式 |
|------|----------|----------|
| **量化** | 量化是确定性操作，对1张图量化 = 对1000张图量化 | 用1个样本验证输出格式和数值有效性 |
| **剪枝** | 剪枝是结构级操作，剪1次 = 剪1000次 | 用1个样本验证稀疏度是否达标 |
| **蒸馏** | 训练趋势可预测，loss下降方向一致 | 用2-3个step验证loss是否下降 |

**实现方法**：
- 蒸馏：运行2-3个训练step，检查`loss_step2 < loss_step1`
- 量化：应用量化后运行1次推理，检查输出shape和NaN/Inf
- 剪枝：应用剪枝后计算稀疏度，检查是否达到目标值

### 验证策略

#### 1. 快速验证策略
- **目标**: 用最少数据验证代码正确性
- **方法**: 
  - 使用dummy数据（随机tensor）
  - 只运行关键代码路径
  - 不保存checkpoint，只验证流程
- **时间**: 每个方法2-3分钟

#### 2. 性能预估策略
- **目标**: 预估轻量化后的性能指标
- **方法**:
  - 参数量：直接计算模型参数（`count_parameters`）
  - 推理速度：用小样本测量（`measure_inference_time`）
  - 压缩比：`student_params / baseline_params`
  - 加速比：`baseline_latency / student_latency`
- **限制**: 精度无法精确预估，只能基于论文数据估算

#### 3. 目标对比策略
- **配置化**: 使用YAML文件配置目标值（`config/verify_targets.yaml`）
- **灵活性**: `null`表示不检查，只输出实际值
- **可扩展**: 支持添加新的性能指标

## 实践方法总结

### 1. 分块验证方法（核心创新）

**原理**：轻量化操作是确定性的，1个样本的结果可以代表全部样本的结果

**实现步骤**：
1. **蒸馏验证**：
   ```python
   # 运行2-3个训练step
   for step in range(3):
       loss = train_one_step(student, teacher, data)
       losses.append(loss)
   # 检查loss是否下降
   if losses[-1] < losses[0]:
       return PASS  # loss下降说明训练方向正确
   ```

2. **量化验证**：
   ```python
   # 应用量化
   quantized_model = quantize_dynamic(model, {torch.nn.Linear}, dtype=torch.qint8)
   # 运行1次推理
   output = quantized_model(sample)
   # 检查输出
   if output.shape == expected_shape and not has_nan(output):
       return PASS  # 输出正确说明量化成功
   ```

3. **剪枝验证**：
   ```python
   # 应用剪枝
   prune.l1_unstructured(module, 'weight', amount=0.4)
   # 计算稀疏度
   sparsity = count_zeros(module) / total_params
   # 检查是否达标
   if sparsity >= target_sparsity:
       return PASS  # 稀疏度达标说明剪枝成功
   ```

### 2. 性能预估方法

**参数量预估**：
- 直接计算：`params = sum(p.numel() for p in model.parameters())`
- 压缩比：`compression = student_params / baseline_params`

**速度预估**：
- 小样本测量：使用`Timer`类测量推理时间
- 加速比：`speedup = baseline_latency / student_latency`

**精度预估**：
- 基于论文数据：参考相关论文的精度损失范围
- 基于模型结构：Student模型结构已知，可预估精度范围

### 3. 错误处理方法

**分层检查**：
1. **代码级检查**：语法错误、导入错误
2. **运行时检查**：模型加载、推理执行
3. **结果检查**：输出格式、数值有效性
4. **性能检查**：参数量、速度、精度

- 失败时跳过样本，不添加无效数据
- 统计成功/失败数量
- 检查有效结果比例（至少50%）

### 4. 配置化设计方法

**YAML配置**：
```yaml
targets:
  params_M: null              # null = 不检查，只输出
  latency_ms: 300.0           # 有值 = 检查并判断PASS/FAIL
  speedup: 2.0
  sparsity: 0.4
```

**优势**：
- 灵活性：可以跳过不需要检查的项
- 可维护性：修改配置不需要改代码
- 可扩展性：可以轻松添加新的检查项

## 详细功能清单

### 脚本1: verify_lightweight_feasibility.py 功能清单

#### 核心验证函数
1. **`verify_distillation(device='cuda')`**
   - 功能：验证蒸馏过程能否成功运行
   - 步骤：
     - 加载Teacher模型（DUSt3R baseline）
     - 创建Student模型（dust3r_student_s）
     - 创建虚拟数据集（2个样本）
     - 运行3个训练step，记录loss
     - 检查loss是否下降（loss_step3 < loss_step1）
   - 输出：`{'passed': bool, 'losses': [float], 'message': str}`
   - 时间：约1-2分钟

2. **`verify_quantization(device='cuda')`**
   - 功能：验证量化过程能否成功运行
   - 步骤：
     - 加载baseline模型
     - 将模型移到CPU（INT8量化必须在CPU上）
     - 应用INT8动态量化（只量化Linear层）
     - 运行1次推理（使用dummy数据）
     - 检查输出shape和数值有效性（无NaN/Inf）
   - 输出：`{'passed': bool, 'output_shape': tuple, 'has_nan': bool, 'message': str}`
   - 时间：约1-2分钟

3. **`verify_pruning(device='cuda', target_sparsity=0.4)`**
   - 功能：验证剪枝过程能否成功运行
   - 步骤：
     - 加载baseline模型
     - 应用L1非结构化剪枝（40%稀疏度）
     - 计算实际稀疏度
     - 检查稀疏度是否达到目标
   - 输出：`{'passed': bool, 'sparsity': float, 'target_sparsity': float, 'message': str}`
   - 时间：约1分钟

#### 辅助功能
- **`DummyPairDataset`**: 虚拟图像对数据集，用于快速验证
- **命令行接口**: 支持`--method`, `--device`, `--target-sparsity`, `--output`参数
- **JSON报告**: 保存验证结果到JSON文件
