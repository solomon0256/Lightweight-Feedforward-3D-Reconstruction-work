## 📋 项目核心定位

### 研究目标
**系统性轻量化 DUSt3R 前馈式 3D 重建 Transformer 模型**，使用三种方法（Pruning、Quantization、Knowledge Distillation），目标发表中档 SCI 论文。

### 核心方法（PQK）
1. **P (Pruning)**: 结构化剪枝 - 减少注意力头、隐藏单元或 FFN
2. **Q (Quantization)**: FP32 → FP16/INT8 量化（PTQ + QAT）
3. **K (Knowledge Distillation)**: 训练轻量 Student 模型逼近 Teacher

### 项目特点
- **预算限制**: $300-400（最小方案）
- **实验路径**: K-only → Q-only → K→Q（不做剪枝）
- **验证机制**: 两道门禁（Smoke Gate + Trend Gate）
- **工作环境**: 本地验证 + 服务器运行

---

## 🔒 验证机制：两道门禁系统

### Smoke Gate（冒烟测试）
**本质**: 快速验证轻量化后的模型能否正常运行

**验证内容**:
1. **轻量化过程验证**: 检查蒸馏/量化/剪枝过程是否成功
2. **Schema 断言**: 输出字段、dtype、shape 是否正确
3. **Golden 对比**: 与 baseline 输出对比，确保数值一致性
4. **稳定性检查**: NaN/Inf 率、崩溃率必须为 0

**运行环境**:
- 数据规模: 16 对样本（Smoke Set）
- 运行时间: 2-5 分钟
- 验证对象: 轻量化后的模型

**关键实现**:
- `scripts/smoke_gate.py`: 完整实现，支持 K/Q/P 三种方法
- `verify_lightweighting_process()`: 验证轻量化过程本身
- 支持可复现的随机选择（seed 参数）

### Trend Gate（趋势预警）
**本质**: 用小规模数据（200对）预测大规模数据（1000对）的结果

**验证内容**:
1. **精度护栏**: absrel、delta1、visloc_acc 的下降阈值（固定阈值）
2. **性能护栏**: 延迟、显存变化检查
3. **趋势分析**: 200对样本的统计结果

**运行环境**:
- 数据规模: 200 对样本（Trend Set）
- 运行时间: 30-60 分钟
- 验证对象: 轻量化后的模型

**关键实现**:
- `scripts/trend_gate.py`: 完整实现，支持实际评测
- `run_trend_evaluation()`: 运行评测并获取指标
- 固定阈值配置（针对最终结果，不随训练进度变化）

**阈值配置**（`config/eval_contract.yaml`）:
- 蒸馏: absrel↑<5%, delta1↓<2%, visloc_acc↓<3%
- 量化 FP16: absrel↑<1%, delta1↓<1%, visloc_acc↓<2%
- 量化 INT8 PTQ: absrel↑<10%, delta1↓<3%, visloc_acc↓<5%
- 量化 INT8 QAT: absrel↑<5%, delta1↓<2%, visloc_acc↓<3%
- 剪枝: absrel↑<8%, delta1↓<3%, visloc_acc↓<5%

## 🛠️ 技术实现核心

### 1. 验证脚本体系

#### `verify_lightweight_feasibility.py`
**功能**: 验证轻量化能否成功运行
- 蒸馏验证: 运行2-3个训练step，检查loss是否下降
- 量化验证: 应用INT8动态量化，检查输出格式和数值有效性
- 剪枝验证: 应用剪枝，检查稀疏度是否达标

**核心原理**: 分块验证 - 轻量化操作是确定性的，1个样本的结果可以代表1000个样本的结果

#### `verify_performance.py`
**功能**: 预估轻量化后的性能指标

- 推理速度测量
- 压缩比/加速比计算

## 🔧 关键技术细节

### DUSt3R 模型特点
1. **输入格式**: 需要 view 字典格式
   ```python
   view1 = {
       'img': img1,           # Tensor: (B, 3, H, W)
       'instance': ['0'],     # List[str]
       'idx': [0]             # List[int]
   }
   ```

2. **输出格式**: 字典，包含 `pts3d`, `conf`, `depth` 等

3. **模型来源**: HuggingFace Hub (`naver/DUSt3R_ViTLarge_BaseDecoder_512_dpt`)

### 分块验证原理
**核心思想**: 轻量化操作是确定性的，1个样本的结果可以代表全部样本的结果

| 方法 | 分块原理 | 验证方式 |
|------|----------|----------|
| **量化** | 量化是确定性操作 | 用1个样本验证输出格式和数值有效性 |
| **剪枝** | 剪枝是结构级操作 | 用1个样本验证稀疏度是否达标 |
| **蒸馏** | 训练趋势可预测 | 用2-3个step验证loss是否下降 |

### 错误处理策略
1. **编码问题**: Windows GBK → UTF-8，替换 emoji 为文本标记
2. **CUDA 显存**: 量化前移到 CPU，量化后移回原设备
3. **Shape 不匹配**: 添加 shape 转换逻辑
4. **错误检查**: 添加成功/失败计数，检查有效结果比例（至少50%）

## 🔑 关键洞察

### 1. Trend Gate 的正确理解
- **错误理解**: 阈值根据训练进度动态调整
- **正确理解**: 阈值是固定的，针对最终结果，用小规模数据预测大规模数据

### 2. Smoke Gate 的本质
- **不是验证脚本，而是验证模型**
- 验证轻量化后的模型能否正常运行
- 用真实数据运行真实模型

### 3. 分块验证原理
- 轻量化操作是确定性的
- 1个样本的结果可以代表1000个样本的结果
- 大大提高了验证效率

### 4. 配置化设计
- 使用 YAML 配置文件
- 支持 `null` 跳过检查项
- 提高了灵活性和可维护性
