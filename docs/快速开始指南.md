## 📝 第六步：生成训练pairs列表

```bash

    --processed_dir datasets/megadepth_processed \

    --output_train datasets/train_pairs.lst \
    --output_val datasets/val_pairs.lst \
    --train_ratio 0.9
```

## ⚠️ 常见问题

### SSH断开
- 使用tmux: `tmux new -s session_name`
- 重新连接: `tmux attach -t session_name`

### GPU显存不足
- 编辑 `expconfigs/distill.yaml`
- 修改 `batch_size: 1` (更小)

### 数据下载慢
- 使用tmux后台运行
- 检查网络连接
