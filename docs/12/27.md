## ⚠️ 注意事项

### 1. 数据路径依赖

- Smoke Gate 和 Trend Gate 都需要从 `config/workload.yaml` 读取 `data.eval_pairs_list`
- 如果数据文件不存在，会给出清晰的错误提示

### 2. 模型加载

- FP16 转换：直接使用 `model.half()`
- INT8/Student/Pruned 模型：需要提供 checkpoint 路径，目前使用 baseline 作为 fallback

### 3. GT 数据

- Smoke Gate 创建 golden 时可能没有 GT（使用 None）
- Trend Gate 评测时也可能没有 GT（使用 None）
- `evaluate_pair()` 函数会处理 GT 为 None 的情况

### 4. 性能测量

- 显存测量仅在 CUDA 设备上有效
- 延迟测量使用 BatchTimer，包含 warmup 和多次测量
