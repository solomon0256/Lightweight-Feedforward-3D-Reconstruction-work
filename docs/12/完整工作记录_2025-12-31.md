### ❌ 错误2: 多次失败的sed/perl命令

**时间**: 尝试修复服务器脚本时

**错误描述**:
我尝试用shell命令修改服务器上的 `train_distill.py`，将 `early_stop_patience` 从3改为10：

```bash
# 尝试1: sed命令 - 失败
ssh ... "sed -i 's/early_stop_patience.*3/early_stop_patience\", 10/' ..."
# 结果: 引号转义问题，命令无效

# 尝试2: perl命令 - 失败
ssh ... "perl -i -pe 's/.../.../g' ..."
# 结果: 引号嵌套问题，命令无效

# 尝试3: awk命令 - 失败
ssh ... "awk '{gsub(...)}' ... > temp && mv temp ..."
# 结果: 管道和重定向问题，命令无效

# 尝试4: Python heredoc - 部分成功但破坏了脚本
ssh ... "python3 << 'EOF' ... EOF"
# 结果: 修改了错误的位置，破坏了脚本逻辑
```

**后果**: 服务器上的 `train_distill.py` 被损坏多次

**教训**: 
- 复杂的远程文件编辑不要用shell命令
- 应该直接用scp上传本地修改好的文件

---
