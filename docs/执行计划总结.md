## 注意事项

1. **网络稳定性**: MegaDepth下载量大，必须使用tmux
2. **磁盘空间**: 确保有足够空间（MegaDepth需要100GB+）
3. **GPU显存**: 根据显存调整batch_size
4. **训练时间**: 预计数天（取决于GPU和数据量）
5. **SSH连接**: 使用tmux/nohup避免断开
