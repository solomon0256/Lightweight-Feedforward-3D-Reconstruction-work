## ⚠️ 注意事项

```bash

```

### 如果设置脚本失败

可以手动执行：

```bash
# 1. 安装PyTorch
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 2. 安装依赖
pip install -r requirements.txt

# 3. 下载模型权重
python scripts/download_weights.py
```
