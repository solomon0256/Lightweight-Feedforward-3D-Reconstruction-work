## 目标

在服务器上运行轻量化程序之前，在本地工作电脑上进行预检，确保：
1. 轻量化程序能成功运行
2. 轻量化后的结果能达到预期性能

**核心约束：轻量化程序只准在服务器上运行一次，必须一次成功。**

## 核心原理：分块验证

**轻量化是可分块的**：跑1个样本的结果 = 跑1000个样本的结果

| 方法 | 能分块吗 | 说明 |
|------|----------|------|
| **量化** | ✅ 能 | 量化1张图的结果 = 量化1000张图的结果 |
| **剪枝** | ✅ 能 | 剪枝1次的结果 = 剪枝1000次的结果 |
| **蒸馏** | ✅ 能 | 跑1个epoch的loss趋势 → 预测完整训练的收敛 |

**结论**：
- 在工作电脑上跑1个样本验证结果正确 → 服务器跑1000个也正确
- 在工作电脑上跑1个样本性能符合预期 → 服务器跑1000个也符合预期

## 需要的两个脚本

### 脚本1：轻量化结果正确性验证脚本

**目的**：用1个样本验证轻量化后的**结果**是否正确

**验证内容**：
- [ ] 蒸馏：跑1个样本，检查loss是否正常下降
- [ ] 量化：跑1个样本，检查输出格式和数值是否正确
- [ ] 剪枝：跑1个样本，检查稀疏度是否达到目标

**验证逻辑**：
```
1. 跑1个样本的蒸馏 → 检查loss是否下降 → 下降说明蒸馏正确
2. 跑1个样本的量化 → 检查输出是否正确 → 正确说明量化正确
3. 跑1个样本的剪枝 → 检查稀疏度是否达标 → 达标说明剪枝正确
4. 如果1个OK → 服务器跑1000个也OK
```

**运行方式**：
- 在工作电脑上运行
- 快速执行（几分钟内完成）
- 只需要1个真实样本

**输出**：
- PASS：1个样本的结果正确，服务器可以运行
- FAIL：列出失败项和错误原因

---

### 脚本2：性能达标验证脚本

**目的**：用1个样本验证轻量化后的**性能**是否符合预期

**验证内容**：
- [ ] 参数量：Student模型参数量是否达到压缩目标
- [ ] 推理速度：1个样本的推理时间是否达到加速目标
- [ ] 精度：1个样本的输出精度是否在可接受范围
- [ ] 输出格式：输出shape和数据类型是否正确

**验证逻辑**：
```
1. 跑1个样本 → 测参数量、速度、精度
2. 对比目标 → 逐项判断PASS/FAIL
3. 如果1个符合预期 → 服务器跑1000个也符合预期
```

**运行方式**：
- 在工作电脑上运行
- 快速执行（几分钟内完成）
- 只需要1个真实样本

**输出**：
- 性能报告（参数量、速度、精度）
- 逐项PASS/FAIL判断
- 总体是否达标

## 验证脚本设计

### 脚本逻辑

```
1. 读取 config/verify_targets.yaml
2. 运行1个样本的轻量化
3. 测量实际结果
4. 对比目标（如果目标为null则跳过该项检查）
5. 输出报告
```

### 灵活性

- 目标值为 `null` → 该项不检查，只输出实际值
- 目标值有数值 → 该项检查，输出 PASS/FAIL

### Step 1：创建 `config/verify_targets.yaml`

定义可配置目标值接口，默认为 `null`（跳过检查），实验时填入具体数值。

```yaml
# 轻量化验证目标配置
# null = 不检查该项，只输出实际值
# 有数值 = 检查并判断 PASS/FAIL

baseline:
  params_M: 571.17
  latency_ms: 353.07
  vram_GB: 2.76

targets:
  # === 参数量目标 ===
  params_M: null              # 目标参数量(M)
  compression_ratio: null     # 目标压缩比 (如 0.1 表示压缩到原来的10%)
  
  # === 速度目标 ===
  latency_ms: null            # 目标推理时间(ms)
  speedup: null               # 目标加速比 (如 2.0 表示快2倍)
  
  # === 精度目标 ===
  max_loss_increase: null     # 蒸馏时允许的最大loss增量
  max_precision_drop_pct: null # 最大精度损失百分比
  
  # === 剪枝目标 ===
  sparsity: null              # 目标稀疏度 (如 0.4 表示40%稀疏)
  
  # === 量化目标 ===
  quant_output_valid: true    # 量化输出是否有效（非NaN/Inf）
```
