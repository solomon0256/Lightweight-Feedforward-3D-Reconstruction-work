## 阶段3: 数据集准备

### 3.1 MegaDepth数据集下载

使用tmux后台下载（避免SSH断开）:
```bash
tmux new -s megadepth_download
cd /root/Lightweight-Feedforward-3D-Reconstruction-work
bash scripts/download_megadepth.sh
```

监控进度:
```bash
# 在另一个终端
tail -f /tmp/megadepth_download.log
```

**重要**: MegaDepth原始数据需要从官方网站手动下载:
- 地址: https://www.cs.cornell.edu/projects/megadepth/
- 下载后解压到: `/root/Lightweight-Feedforward-3D-Reconstruction-work/datasets/megadepth`

预期时间: 数小时（取决于网络速度）

### 3.2 生成训练pairs列表

预处理完成后，生成pairs列表:
```bash
python scripts/prepare_megadepth_pairs.py \
    --processed_dir datasets/megadepth_processed \
    --pairs_file datasets/megadepth/megadepth_pairs.npz \
    --output_train datasets/train_pairs.lst \
    --output_val datasets/val_pairs.lst \
    --train_ratio 0.9
```

验证生成的文件:
```bash
wc -l datasets/train_pairs.lst datasets/val_pairs.lst
head -5 datasets/train_pairs.lst
```

### 3.3 确认7-Scenes数据集（评估用）

## 阶段4: 训练配置

### 4.1 检查配置文件

检查 `expconfigs/distill.yaml` 配置:
- Student配置是否匹配（当前使用Student-S: 9层encoder, 512维）
- 数据路径是否正确
- 训练超参数是否合理

### 4.2 训练参数确认

根据GPU显存调整batch size:
- 如果GPU显存 >= 24GB: `batch_size: 4`
- 如果GPU显存 < 24GB: `batch_size: 1` (当前配置)

其他参数:
- `lr: 2e-4` (学习率)
- `max_epochs: 30`
- `early_stop_patience: 10`

## 故障排查

### 常见问题

1. **GPU显存不足**
   - 减小batch_size
   - 使用gradient accumulation

2. **数据加载慢**
   - 增加num_workers
   - 检查磁盘I/O

3. **训练中断**
   - 检查checkpoint恢复功能
   - 使用tmux保持会话

4. **SSH连接断开**
   - 使用tmux/nohup运行长时间任务
   - 配置SSH KeepAlive
