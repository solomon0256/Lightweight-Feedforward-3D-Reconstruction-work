# 服务器部署操作步骤（手动执行）

> **日期**: 2025-12-30  
> **目标**: 在vast.ai服务器上部署项目并配置环境

---

## 🚀 完整操作步骤

### 步骤1：连接服务器

**在Windows Terminal中执行**:
```bash
ssh -p 10361 root@192.165.134.28
```

**首次连接会提示**:
```
The authenticity of host '192.165.134.28' can't be established.
Are you sure you want to continue connecting (yes/no)?
```
输入: `yes`

**如果需要密码**:
- 在vast.ai控制台查看密码
- 或使用SSH密钥（如果配置了）

---

### 步骤2：验证连接

**连接成功后，验证环境**:
```bash

pwd

# 检查Python
python3 --version

# 检查GPU
nvidia-smi

# 检查Git
git --version
```

---

### 步骤3：克隆项目

**克隆项目（包含submodule）**:
```bash
# 克隆项目
git clone --recursive https://github.com/solomon0256/Lightweight-Feedforward-3D-Reconstruction-work.git

# 进入项目目录
cd Lightweight-Feedforward-3D-Reconstruction-work

# 检查项目结构
ls -la

# 检查submodule是否下载
ls third_party/dust3r/
```

**如果忘记加`--recursive`，补救方法**:
```bash
cd Lightweight-Feedforward-3D-Reconstruction-work
git submodule update --init --recursive
```

## ⚠️ 常见问题

### 问题1：SSH连接失败

**可能原因**:
- 密码错误
- 端口错误
- 服务器未启动

**解决方法**:
- 检查vast.ai控制台，确认实例状态
- 确认SSH端口和IP地址
- 尝试使用代理连接：`ssh -p 26079 root@ssh5.vast.ai`

---

### 问题2：Git克隆失败

**可能原因**:
- 网络问题
- GitHub访问受限

**解决方法**:
```bash
# 检查网络
ping github.com

# 如果GitHub不可用，可以尝试使用代理或镜像
```

---

### 问题3：Submodule未下载

**解决方法**:
```bash
cd Lightweight-Feedforward-3D-Reconstruction-work
git submodule update --init --recursive
```

---

### 问题4：setup_server.sh失败

**可能原因**:
- PyTorch安装失败
- 依赖包安装失败

**解决方法**:
```bash
# 手动安装PyTorch
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 手动安装依赖
pip install -r requirements.txt
```
